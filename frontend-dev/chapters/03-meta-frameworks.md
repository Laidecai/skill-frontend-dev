## 🏗️ 元框架（全栈框架）

| 项目 | Stars | 用途 | 框架基础 | 安装 |
|------|-------|------|----------|------|
| **vercel/next.js** | 130k+ | ⭐ React SSR/SSG/ISR + App Router + Server Actions | React | `npm i next` |
| **nuxt/nuxt** | 56k+ | ⭐ Vue SSR/SSG + 自动导入 + 模块生态 | Vue | `npm i nuxt` |
| **remix-run/remix** | 31k+ | React 全栈（Web 标准表单/加载） | React | `npm i @remix-run/react` |
| **withastro/astro** | 50k+ | ⭐ 内容站点框架（岛屿架构/多框架） | 多框架 | `npm i astro` |
| **sveltejs/kit** | 19k+ | Svelte 全栈框架 | Svelte | `npm i @sveltejs/kit` |
| **gatsbyjs/gatsby** | 56k+ | React 静态站点生成器 | React | `npm i gatsby` |
| **solidjs/solid-start** | 5k+ | Solid 全栈框架 | Solid | `npm i @solidjs/start` |
| **analogjs/analog** | 5k+ | Angular 全栈框架（类似 Next.js） | Angular | `npm i @analogjs/platform` |

### 元框架选型指南

| 需求 | 推荐 | 理由 |
|------|------|------|
| SEO 优化内容站点 | **Astro** / **Next.js** | Astro 岛屿架构零 JS；Next.js SSR/SSG |
| 企业级 Web App | **Next.js** | 最成熟、生态最全、RSC/Server Actions |
| 快速原型/中小型项目 | **Nuxt** | Vue 生态便捷、模块丰富 |
| 电商/表单密集应用 | **Remix** | Web 标准表单、渐进增强 |
| 文档/博客站点 | **Astro** | 内容驱动、多框架组件支持 |
| 极简高性能应用 | **SvelteKit** | 编译优化、包体积小 |
